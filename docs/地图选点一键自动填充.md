# 🎯 地图选点一键自动填充功能

## ✨ 新功能：真正的自动填充！

现在你可以在地图上点击，**坐标会自动填充到输入框**，无需手动复制粘贴！

---

## 🚀 使用方法

### 1. 启动应用

```bash
streamlit run src/streamlit_app.py
```

### 2. 进入路线规划页面

在左侧导航栏点击 **"🗺️ 路线规划"**

### 3. 选择手动坐标模式

在页面上选择 **"手动坐标"** 单选按钮

### 4. 启用地图选点模式 ⭐ 关键步骤

勾选 **"🗺️ 启用地图选点模式"** 复选框

### 5. 选择起点

1. 点击 **"🟢 选择起点"** 按钮（按钮会高亮显示）
2. 在下方地图上点击任意位置
3. ✅ 起点坐标会**自动填充**到输入框
4. 地图会显示绿色标记

### 6. 选择终点

1. 点击 **"🔴 选择终点"** 按钮（按钮会高亮显示）
2. 在下方地图上点击任意位置
3. ✅ 终点坐标会**自动填充**到输入框
4. 地图会显示红色标记
5. 两点之间会显示蓝色虚线

### 7. 应用坐标

点击 **"✅ 应用坐标"** 按钮，页面会自动刷新并显示🎈

### 8. 生成路线

向下滚动，系统会自动使用新坐标计算路线

## 🛠️ 技术实现

### 使用的库
- `streamlit-folium==0.27.2` - Streamlit 和 Folium 的桥接组件
- `folium==0.20.0` - 交互式地图库

### 核心机制
1. 使用 `st_folium()` 渲染交互式地图
2. 监听地图的 `last_clicked` 事件
3. 根据当前模式（起点/终点）更新对应的 `session_state`
4. 使用 `st.rerun()` 刷新页面，触发输入框更新

### Session State 管理
```python
st.session_state.route_origin_lat    # 起点纬度
st.session_state.route_origin_lng    # 起点经度
st.session_state.route_dest_lat      # 终点纬度
st.session_state.route_dest_lng      # 终点经度
st.session_state.map_picker_step     # 当前模式（0=起点, 1=终点）
```

## 📋 常见问题

### Q: 为什么需要勾选"启用地图选点模式"？
A: 为了不影响原有的手动输入功能，地图选点是可选功能。勾选后才会显示交互式地图。

### Q: 点击地图后坐标没有更新？
A: 确保：
1. 已勾选"启用地图选点模式"
2. 已点击"选择起点"或"选择终点"按钮
3. 等待页面自动刷新

### Q: 能否同时使用手动输入和地图选点？
A: 可以！地图选点会更新输入框的值，你也可以手动修改输入框中的数字。

### Q: 如何重新选择起点或终点？
A: 点击对应的按钮（🟢 选择起点 或 🔴 选择终点），然后在地图上点击新位置即可。

### Q: 坐标精度是多少？
A: 显示和使用的精度都是小数点后6位（约0.1米精度）。

## 💡 使用技巧

1. 先用"历史OD端点"查看常用路线
2. 切换到"手动坐标"模式
3. 用地图选点选择相似区域
