# 地图选点功能使用指南

## 功能概述

在路线规划页面，你可以通过点击地图来选择起点和终点坐标，无需手动输入经纬度。

## 使用步骤

### 1. 启动应用

```bash
streamlit run src/streamlit_app.py
```

### 2. 进入路线规划页面

在左侧导航栏选择 **"路线规划"** 功能模块。

### 3. 选择坐标输入模式

在页面上方选择 **"手动坐标"** 模式。

### 4. 生成地图

使用默认坐标或输入任意初始坐标，点击生成路线按钮，会显示包含选点功能的地图。

### 5. 在地图上选择起点和终点

#### 第一次点击 - 选择起点
- 点击地图上的任意位置
- 地图会显示一个绿色标记（起点）
- 左下角面板会显示起点坐标

#### 第二次点击 - 选择终点
- 继续点击地图上的另一个位置
- 地图会显示一个红色标记（终点）
- 两点之间会显示蓝色虚线连接
- 左下角面板会显示起点和终点的完整坐标
- **三个复制按钮会出现**

### 6. 复制坐标

选择完起点和终点后，会出现三个按钮：

| 按钮 | 功能 | 复制格式 |
|------|------|----------|
| 📋 复制起点 | 复制起点坐标 | `纬度,经度` |
| 📋 复制终点 | 复制终点坐标 | `纬度,经度` |
| 📦 复制全部 | 复制起点和终点坐标 | 两行：起点坐标\n终点坐标 |

点击按钮后：
- 坐标会自动复制到剪贴板
- 按钮会显示 **"✓ 已复制"** 反馈（1.8秒）
- 按钮会有缩放动画效果

### 7. 粘贴到输入框

1. 点击 **"📋 复制起点"**
2. 将复制的内容粘贴到 **"起点纬度"** 输入框（只粘贴纬度值）
3. 将复制的内容粘贴到 **"起点经度"** 输入框（只粘贴经度值）
4. 重复上述步骤复制粘贴终点坐标

### 8. 重新生成路线

粘贴完坐标后，点击 **"生成路线"** 按钮，系统会使用新坐标计算路线。

### 9. 重新选择（可选）

如果要重新选择起点和终点：
- 直接点击地图第三次，会自动清除之前的选择
- 重新开始选择起点

### 单个坐标格式
```

```

### 全部坐标格式
```
22.528470,114.054540
22.600800,114.101000
```

## 技术限制说明

由于 Streamlit 的技术架构限制，地图（iframe）无法直接与页面输入框通信，因此：

- ❌ 无法实现"自动填充"到输入框
- ✅ 提供"一键复制"功能作为替代方案
- ✅ 复制后可快速粘贴到输入框

这是目前最优的解决方案，相比手动输入已经大大提升了效率。

## 快捷操作技巧

1. **快速重选**：直接点击地图第三次会清除之前的选择
2. **键盘快捷键**：复制后使用 `Ctrl+V`（Windows）或 `Cmd+V`（Mac）快速粘贴
3. **批量操作**：使用"复制全部"可以一次复制所有坐标，然后分别粘贴

## 浏览器兼容性

- ✅ Chrome / Edge（推荐）
- ✅ Firefox

## 常见问题

### Q: 点击复制按钮没有反应？
A: 确保浏览器允许访问剪贴板，检查浏览器设置中是否启用了剪贴板权限。

### Q: 复制的坐标格式不对？
A: 复制的格式为 `纬度,经度`（逗号分隔），粘贴时需要分别提取纬度和经度值。

### Q: 能否直接自动填充到输入框？
A: 由于 Streamlit 技术限制，目前无法实现真正的自动填充，但一键复制已经大大简化了操作。

### Q: 选错了怎么办？
A: 直接点击地图第三次会自动清除之前的选择，重新开始。
