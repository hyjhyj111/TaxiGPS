# 路线规划功能说明

## 功能概述

路线规划功能支持通过地图点击选择起点和终点，自动计算**最短距离路线**和**基准最快路线**。

## 核心特性

### 1. 交互式地图选点
- **第一次点击**：设置起点（绿色标记 🟢）
- **第二次点击**：设置终点（红色标记 🔴）
- **第三次点击**：清除当前选点，重新开始

### 2. 双路线计算
- **最短距离路线**（蓝色线）：道路长度总和最小
- **基准最快路线**（绿色线）：基于历史平均速度的通行时间最短

### 3. 路网校正缓存复用
- 自动使用已有的校正车辆轨迹生成道路基准速度
- 首次计算会生成速度缓存，后续查询直接复用
- 没有车辆缓存时使用道路类型默认速度

## 使用步骤

### 步骤 1：选择车辆（可选）
在侧边栏选择车辆ID，用于生成更准确的道路速度样本。

### 步骤 2：进入路线规划页面
点击左侧导航栏的 **🗺️ 路线规划**。

### 步骤 3：选择起点和终点
1. 在地图上点击选择起点（显示绿色标记）
2. 再次点击选择终点（显示红色标记）
3. 系统会显示虚线连接两点

### 步骤 4：计算路线
点击 **✅ 计算路线** 按钮，等待计算完成。

### 步骤 5：查看结果
- 地图上显示蓝色（最短）和绿色（最快）两条路线
- 下方显示详细统计信息：
  - 距离对比
  - 预计时间
  - 道路边数量
  - 节点数量

### 步骤 6：重新规划（可选）
点击 **🔄 重新选点** 按钮清除当前选点，开始新的规划。

## 技术实现

### 路线算法
- **最短距离路线**：使用 Dijkstra 算法，权重为道路长度（`length`）
- **基准最快路线**：使用 Dijkstra 算法，权重为通行成本（`route_cost`）

### 道路速度来源优先级
1. **道路历史平均速度**：从校正车辆轨迹统计（样本数 ≥ 3）
2. **同类道路速度中位数**：相同 `highway` 类型的可靠速度中位数
3. **道路类型默认速度**：预设的各类道路标准速度
4. **全局回退速度**：30 km/h

### 通行成本计算
```python
route_cost (秒) = length (米) / speed (km/h) * 3.6
```

## 性能优化

### 缓存机制
- **道路速度缓存**：自动保存到 `cache/edge_baseline_speed.parquet`
- **路线计算缓存**：相同起终点和车辆组合会使用缓存结果
- **路网加载缓存**：路网文件只加载一次

### 速度提升
- 首次计算：10-30 秒（需生成速度缓存）
- 后续计算：2-5 秒（复用缓存）

## 注意事项

1. **路网文件要求**
   - 需要 `shenzhen_drive.pkl` 或 `shenzhen_drive.graphml`
   - 放置在项目根目录、`data/` 或 `cache/` 目录

2. **车辆数量限制**
   - 最多使用 100 辆车生成速度样本
   - 避免处理过多轨迹影响性能

3. **点击位置**
   - 会自动吸附到最近的路网节点
   - 吸附距离过大时可能影响结果准确性

4. **第三次点击**
   - 如果已选择 2 个点，第三次点击会清除并重新开始
   - 也可以使用"重新选点"按钮

## 数据流程

```
用户点击地图
    ↓
保存起点/终点坐标
    ↓
最近节点吸附
    ↓
生成/加载道路速度缓存
    ↓
计算最短距离路线（权重：length）
    ↓
计算基准最快路线（权重：route_cost）
    ↓
返回路线 GeoJSON
    ↓
在地图上渲染路线
```

## 常见问题

### Q1: 为什么首次计算很慢？
**A:** 首次需要从校正车辆轨迹生成道路速度缓存，这需要处理大量数据。后续计算会直接使用缓存，速度会快很多。

### Q2: 两条路线完全重合怎么办？
**A:** 说明最短路线和最快路线是同一条，绿色线会显示为虚线以区分。

### Q3: 没有选择车辆会怎样？
**A:** 系统会使用道路类型的默认速度计算最快路线，结果可能不够准确。建议选择车辆以获得更真实的道路速度。

### Q4: 为什么有些道路没有速度样本？
**A:** 某些道路可能车辆很少经过，系统会使用同类道路速度中位数或默认速度作为回退。

### Q5: 如何导出路线数据？
**A:** 当前版本暂不支持导出，后续版本会添加 JSON/GeoJSON 导出功能。
