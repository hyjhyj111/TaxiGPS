# 出租车GPS轨迹查询系统

出租车GPS轨迹查询系统是一个面向真实出租车 GPS 数据的时空分析与可视化平台，支持多车轨迹查询、分钟级位置查看、OD 上下车点标注、动画轨迹演示，以及热力图与统计分析能力。

## 功能特性

### 轨迹查询
- 支持按车辆 ID 与时间范围查询轨迹
- 支持最多同时选择 10 辆车进行并行展示
- 轨迹按运营状态自动着色，红色表示载客，蓝色表示空载
- 自动读取车辆缓存，不直接扫描原始大表
- 支持点击分钟地图上的车辆点查看后续轨迹预览

### 分钟位置查询
- 支持查看某一分钟所有车辆的位置分布
- 支持按车辆 ID 筛选指定车辆位置
- 自动读取分钟缓存，提升查询响应速度
- 点击地图中的车辆点可展开查看该车后续路径

### OD点标注
- 展示上车点和下车点，并区分线路走向
- 点位较多时自动聚类，减少地图拥挤
- 支持抽样连线展示 OD 路径

### 动画轨迹
- 支持单车和多车动画轨迹回放
- 轨迹按时间顺序平滑播放，展示行驶过程
- 支持播放速度调节，便于观察不同节奏下的轨迹变化
- 动画地图采用更高的清晰度设置，增强显示效果

### 热力图与统计分析
- 支持基于分钟缓存的车辆位置静态热力图
- 支持基于 OD 数据的上车点静态热力图
- 支持按分钟、15 分钟、30 分钟、60 分钟的动态热力图
- 集成 EMA / WMA 平滑算法，改善动态热力图视觉过渡
- 动态热力图已切换为自定义 `Leaflet.heat + requestAnimationFrame` 播放器，支持平滑插值、时间轴拖动和逐帧性能调节
- 支持 DBSCAN 上车点聚类分析，并按聚类中心输出热力图
- 支持小时订单统计、里程区间统计、车辆运营统计
- 支持统计结果导出为 CSV / Excel 文件
- 分钟缓存车辆位置的静态/动态热力图固定按全部车辆统计，不受左侧车辆 ID 筛选影响
- 静态热力图显示范围已收紧为深圳展示范围，避免视野被边缘点拉大

### 边界展示
- 接入深圳市边界文件，便于轨迹与点位在边界范围内展示
- 为后续热力图与更完整的路网校正能力预留基础

## 运行前提

- Python 3.13 或更高版本
- 已准备好车辆缓存、分钟缓存和 OD 结果表
- 已安装 Streamlit、Folium、Pandas、NumPy 等依赖

```

├── cache/           # 缓存目录
│   ├── vehicles/    # 车辆轨迹缓存（按车辆ID存储）

├── data/            # 数据目录
│   ├── raw/         # 原始数据
│   ├── cleaned/     # 清洗后数据
│   └── processed/   # 处理后数据（OD表等）
├── docs/            # 文档目录
├── logs/            # 日志文件
│   ├── map_query.log    # 地图查询日志
│   └── startup_log.txt  # 启动日志
├── pages/           # 可视化页面
│   └── maps/        # 生成的地图HTML文件
├── exports/         # 热力图与统计导出文件
│   └── heatmap_stats/
└── src/             # 源代码
    ├── streamlit_app.py  # Streamlit交互主应用
    └── map_plotter.py    # 地图绘制核心模块
    └── heatmap_analysis.py # 热力图、聚类与统计分析模块
```

## 使用说明

1. 在侧边栏选择车辆 ID，最多可同时选择 10 辆
2. 选择日期，并设置轨迹区间和分钟查询时间
3. 点击“执行查询”后，在顶部切换不同功能模块
4. 轨迹查询优先读取车辆缓存，分钟位置查询优先读取分钟缓存
5. 在分钟位置地图中点击车辆点，可直接展开该车后续路径
6. 在“热力图与统计分析”中可切换静态热力图、动态热力图、订单统计、车辆运营和上车点聚类分析
7. 当热力图数据源为“分钟缓存车辆位置”时，系统固定按全部车辆统计；当数据源为“OD 上车点”时，才会按车辆 ID 筛选执行

## 注意事项

- 轨迹查询优先读取车辆缓存
- 分钟位置查询优先读取分钟缓存
- OD 点标注读取的是处理后的 OD 结果表
- 动画轨迹依赖车辆缓存点位，轨迹点过少时无法播放
- 地图 HTML 文件会输出到 `pages/maps/` 目录
- 统计 CSV / Excel 会输出到 `exports/heatmap_stats/` 目录
- 当前已加入轻量轨迹校正与平滑处理，便于更自然地展示路径
- 动态热力图播放器使用浏览器逐帧动画，首次加载后可通过底部时间轴拖动查看任意时间片
- 静态热力图与动态热力图都带有边界过滤和漂移过滤，分钟热力图默认展示深圳范围

## 数据准备

### 数据格式要求

清洗后的轨迹数据应至少包含以下字段：
- `id` - 车辆ID
- `time` - 时间戳（格式：YYYY-MM-DD HH:MM:SS）
- `long` - 经度
- `lati` - 纬度
- `status` - 状态（0=空载，1=载客）
- `speed` - 速度（km/h）

### 数据处理流程

1. 运行 `data_cleaning.py` 完成原始数据清洗
2. 运行 `clean_od_extraction.py` 提取 OD 上下车点
3. 首次启动系统时会自动构建车辆缓存与分钟缓存
4. 如已接入边界文件，请将 `深圳市.json` 放入 `data/` 目录
