# 基于出租车 GPS 数据的时空特征提取及可视化项目报告

## 1. 项目概况

本项目围绕深圳出租车 GPS 数据完成数据清洗、OD 提取、缓存构建、地图展示、统计分析、路网匹配和 ETA 估计。系统入口为 `run_project.py`，主要输出位于 `outputs/`。

## 2. 数据与字段

原始数据文件为 `TaxiData.csv`，无表头，字段统一为 `id,time,lng,lat,status,speed`。其中 `status=1` 表示载客，`status=0` 表示空客。原始时间仅包含时分秒时，系统补充日期 `2013-10-22`。

## 3. 数据清洗

清洗流程包括字段统一、时间转换、数值类型转换、深圳范围过滤、速度和载客状态合法性过滤、按 `id,time` 排序、复杂重复值保留、短时间 `0-1-0`/`1-0-1` 异常状态剔除。

## 4. OD 提取与缓存

OD 提取基于同一车辆的状态变化：`0 -> 1` 为上车点，`1 -> 0` 为下车点。订单表输出车辆 ID、开始/结束时间、起终点经纬度、耗时、直线距离和平均速度。缓存包括车辆轨迹缓存、分钟位置缓存和 OD 缓存。

## 5. 统计分析与可视化

系统生成小时订单统计、短中长途统计、车辆总里程/载客里程/空驶里程/载客率，以及上车点热点。热点分析优先使用 DBSCAN，依赖不可用时回退为网格聚合。`outputs/maps/dashboard.html` 展示车辆轨迹、车辆位置、上车点和小时订单分布。

## 6. 路网匹配与 ETA

系统解析 `shenzhen_drive.graphml`，对 OD 样例起终点执行最近道路节点匹配，并通过最短路径估计路网距离和 ETA。若最短路径不可达，则回退到球面距离估计。

## 7. 运行方式

快速演示：

```bash
.venv/bin/python run_project.py pipeline --limit-rows 300000
```

全量处理：

```bash
.venv/bin/python run_project.py pipeline --full
```

## 8. 项目成果

代码、运行说明、清洗数据、OD 数据、缓存文件、统计结果、地图 HTML 和 ETA 样例均已集成到统一流程，满足 roadmap 中系统集成与验收准备的主要要求。
